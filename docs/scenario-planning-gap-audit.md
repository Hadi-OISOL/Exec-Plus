# Scenario planning gap audit

Status: Complete for the bounded local/test and private-demo slice. See
[verification](verification-scenario-planning.md).

October 13 authorization starts the researched roadmap in dependency order. This
first slice adds private, immutable comparisons over one confirmed numerical
aggregate. Multiple-variable response models, causal effects, automatic chat jobs,
advanced detection, broader recommendations and external embedding remain later
slices. All eight production gates stay mandatory.

Existing 0016 analysis runs already bind source, creator, confirmed meaning, exact
query receipt, method and checksums. Reopening reproduces typed evidence; ordinary
sharing cannot expose private receipts. Missing parts are scenario calculation,
aggregate completeness checks, an additive kind migration, strict input forms,
immutable successor links and a comparison UI. Reuse these primitives rather than
introduce a second evidence store.

Scope: one eligible SUM or AVG with declared fixed units and governed filters;
one to five named alternatives; each explicitly replaces the aggregate or changes
it by a declared percentage. This changes a hypothetical aggregate, not source rows
or a forecast. User acknowledgment is mandatory. Source missingness, empty
populations and invalid inputs refuse calculation. No unit or revenue formula is
inferred. Percentage differences from zero are unavailable.

Successor runs reference an accessible private prior comparison in the same
dataset and retain compatible metric, aggregation, units and population filters.
They recompute their own current baseline; prior results are preserved. Source
refresh never silently edits or reruns a comparison. Scenario runs cannot use
recommendation approval as if conditional estimates were action decisions.

Acceptance requires independent Decimal fixtures, bounded precision, strict
inputs, exact source replay, immutable succession, missing/empty refusals,
aggregation/meaning/filter guards, tampering, revocation, cross-user denial,
original 0016 compatibility, migration preservation and real browser/mobile flows.
Update the feature audit only after verification; VC 57 can become Partial for
this bounded slice, not Done for broad scenario models.
