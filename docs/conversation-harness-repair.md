# Conversation task repair — October 16

The reported questions “what this data about?” and “i want to know generally what
this data is about” both produced an unrelated capabilities menu. Read-only live
inspection found both stored turns and their succeeded jobs. Each saved plan
selected `inspect_profile` and `assemble_evidence`, but the final router rejected

## Implemented behavior

Deterministic and model-selected overview routes share one executor. Whole-file
orientation reaches the qualitative reading tool; it does not require a named
metric. Model routing handles ordinary paraphrases. Bounded request requirements
prevent a calculation, record restriction, document request or chart from being
silently replaced with prose. They are conflict checks, not a claim of perfect
language understanding. Truly missing inputs still ask for clarification.

The optional selector runs for calculation/record/scope work. General semantic
classification therefore leaves room for the reading and its one correction
inside the existing three-model-call job budget. No budget or provider changes.

New explanation tasks supersede pending calculation work. A bare measure or
genuine continuation retains its pending question and scope. After a completed
new explanation, field explanation, diagram or pattern task, an old calculation
cannot reappear as the meaning of a later short follow-up. Acknowledgements
preserve the active calculation. Saved clarification choices remain available to
the next router call.

An explicit request to explain again may reuse at most 3,500 characters of the
previous explanation. That prose is untrusted, fallible context. It is included
only when an internal digest matches current source/definition references,
private goal, accessible reading notes and personal-memory revision. Forgotten
memory or edited notes/goals cannot be reintroduced through earlier prose.
Historical guides without a digest use current context instead. Digests stay
inside private evidence and are absent from the public response contract.

Current source/access/private context are checked before reading, before a
correction and before publication. Fresh explicit understanding can use a newer
source; a stale continuation cannot silently adopt changed meanings. Old answers
remain immutable. Numerical results still come from authorized executed queries.
